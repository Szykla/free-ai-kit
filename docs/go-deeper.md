# Go deeper, for free

For when the 16 tutorials feel easy and you want to know how the models and agents underneath work. Every link here is free to read, watch or run. Most of it needs Python, and some of it needs maths.

Last checked 22 November 2026. No affiliate links, no sponsors. Where a free resource also sells something, the line says so.

## Watch

| Video | What you get | Level |
|---|---|---|
| [Intro to Large Language Models](https://www.youtube.com/watch?v=zjkBMFhNj_g) (Andrej Karpathy) | A one-hour talk on what an LLM is, how it is trained and where it fails | Anyone. No code |
| [Building Large Language Models](https://www.youtube.com/watch?v=9vM4p9NN0Ts) (Stanford CS229 lecture) | How a ChatGPT-like model is built: pretraining, then post-training | Some maths helps |
| [CS336: Language Modeling from Scratch](https://cs336.stanford.edu/) (Stanford) | A full university course: build your own model, from tokenizer to alignment. [Lectures](https://www.youtube.com/watch?v=JuoVZkPBiKk&list=PLoROMvodv4rMqXOcazWaTUHhq-yembLCV) and [assignments](https://github.com/stanford-cs336) are free | Hard. Strong Python, PyTorch, college maths. Full training runs need a rented GPU, about $5 to $7 an hour |

## Read

| Guide | What you get | Level |
|---|---|---|
| [Building effective agents](https://www.anthropic.com/research/building-effective-agents) (Anthropic) | When to use a simple workflow and when an agent, with the common patterns | Builders. Short |
| [A practical guide to building agents](https://cdn.openai.com/business-guides-and-resources/a-practical-guide-to-building-agents.pdf) (OpenAI, PDF) | Picking models, tools and instructions, and adding guardrails | Builders and managers |
| [Agents whitepaper](https://www.kaggle.com/whitepaper-agents) and [Agent companion](https://www.kaggle.com/whitepaper-agent-companion) (Google, on Kaggle) | How agents use tools and memory, then how to evaluate and run them | Builders |
| [Understanding Deep Learning](https://udlbook.github.io/udlbook/) (Simon Prince) | A full textbook on deep learning, free as a PDF, with notebooks | Hard. Needs maths |

## Build

| Repository | What you get | Catch |
|---|---|---|
| [AI Agents for Beginners](https://github.com/microsoft/ai-agents-for-beginners) (Microsoft) | 18 lessons with code and short videos | None. MIT licence. Some examples use Azure |
| [ML for Beginners](https://github.com/microsoft/ML-For-Beginners) (Microsoft) | 26 lessons of classic machine learning, before LLMs | None. MIT licence |
| [LLM Course](https://github.com/mlabonne/llm-course) (Maxime Labonne) | Roadmaps and Colab notebooks for fine-tuning, quantising and evaluating models | Free. The author also sells a book |
| [Prompt Engineering Guide](https://github.com/dair-ai/Prompt-Engineering-Guide) (DAIR.AI) | Papers, techniques and notebooks on prompting, context, RAG and agents | Free. It has a sponsor and advertises paid courses |
| [GenAI Agents](https://github.com/NirDiamant/GenAI_Agents) (Nir Diamant) | 50+ notebooks, from a simple chat agent to multi-agent systems | Free to learn from, but the licence is non-commercial. The top of the page sells a $199 course |
| [Made With ML](https://github.com/GokuMohandas/Made-With-ML) (Goku Mohandas) | Taking a model from notebook to tested, deployed product | Free. MIT licence. Some parts expect a cloud setup |
| [Designing Machine Learning Systems notes](https://github.com/chiphuyen/dmls-book) (Chip Huyen) | Chapter summaries and tool lists from the book | Only the notes are free. The book itself is paid |
