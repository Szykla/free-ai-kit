## Production notes

- One task per video: this one covers a single conversation, start to finish.
- Record in a clean demo account with no notifications and no past chats in the sidebar. Use a modest window size with larger zoom so text reads on a phone.
- Use a real human voice at a conversational pace. Hold the 2-second pauses marked in the script.
- Use the kit's one highlight style: a pink (#e83e9c) box or numbered pink circle. Use cyan ticks for "checked" items.
- Show every AI reply with the label "Example: yours will differ". Do not read the whole reply aloud; read only the parts the narration names.
- Blur nothing. If anything personal shows on screen, cover it with a solid box.
- On-screen text is limited to short labels. Do not repeat the narration word for word.
- Upload captions made from the Audio column, edited by hand, and publish the same text as the transcript next to the written lesson.
- Re-record when any of the three apps changes its chat page visibly. Last checked: November 2026.
