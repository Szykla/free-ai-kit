## Production notes

- One task per video: run five small tests and write one card.
- Record in a clean demo account with memory switched off and no past chats in the sidebar, so step 7 behaves as described. Say so in the description.
- Use a modest window size with larger zoom so text reads on a phone.
- Use a real human voice at a conversational pace. Hold the marked pauses.
- One highlight style across the kit: pink (#e83e9c) box or numbered circle. Cyan tick for "it worked".
- Label every AI reply on screen "Example: yours will differ". If the demo account gets an honest "I don't know" in step 4, keep it; do not re-run until it invents something.
- Show the toggle in one app on screen; name the other two in the narration only.
- Keep on-screen text to short labels; do not repeat the narration word for word.
- Upload hand-edited captions made from the Audio column, and publish the same text as the transcript next to the written lesson.
- Re-record when any app moves its temporary chat control. Last checked: November 2026.
