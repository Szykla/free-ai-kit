## Production notes

- Keep this video to the one task above. It runs about 4 minutes at a calm pace.
- Record in a clean demo account with no notifications, at a modest window size with larger zoom so text is readable on phones.
- Use a real human voice, conversational, with 2-5 second pauses after key actions where marked.
- Use the kit's one highlight style: a pink (#e83e9c) box or numbered callout. Nothing else on screen should be pink.
- Show AI replies with the on-screen label "Example: yours will differ". Do not edit replies to look perfect.
- Avoid on-screen text that repeats the narration word for word, apart from the short part labels.
- Any assistant works for this video. Name it once on screen. Do not show logos in the thumbnail.
- Upload edited captions made from the Audio column, and publish this script as the transcript next to the written tutorial.
- Re-record when the chat window changes visibly.
