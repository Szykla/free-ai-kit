## Production notes

- Keep this video to the one task above. It runs about 4 minutes 30 seconds.
- Record in a clean demo account with no notifications, at a modest window size with larger zoom so text is readable on phones.
- Use a real human voice at a conversational pace, with 2-5 second pauses after key actions where marked.
- Use the kit's one highlight style: a pink (#e83e9c) box or numbered callout. The cyan "Checked" tag is the only other colour accent.
- Show AI replies with the on-screen label "Example: yours will differ". If your real reply gets the sack count right, say so and show the code check anyway.
- Do not present any one country's labelling rule as fact. Crop the source page tightly to the matching sentence, or use a placeholder page.
- Avoid on-screen text that repeats the narration word for word, apart from short labels.
- Upload edited captions made from the Audio column, and publish this script as the transcript next to the written tutorial.
- Re-record when the chat window or the tools button changes visibly.
