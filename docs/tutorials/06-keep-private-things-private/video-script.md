## Production notes

- Keep this video to the one task above. It runs about 5 minutes, because it shows three apps. If it runs over 6 minutes, split rows 4 to 7 into one short video per app.
- Record in a clean demo account with no notifications and no real memories. Use a modest window size with larger zoom, so text is readable on phones.
- Hide any personal data on screen with a solid box, not blur.
- Use a real human voice at a conversational pace, with 2-5 second pauses after key actions where marked.
- Use the kit's one highlight style: a pink (#e83e9c) box or numbered callout.
- Settings pages change often. Re-check all three help pages on the day you record, and re-record when a menu path changes.
- Avoid on-screen text that repeats the narration word for word, apart from short labels.
