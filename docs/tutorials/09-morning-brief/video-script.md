## Production notes

- Record in a clean demo Google account filled with fake bakery emails and calendar events. Never show a real inbox; use solid boxes, not blur.
- Free tasks run in a flexible morning window, so you can't film the exact arrival. Run the task once, then record the notification and result the next morning. Say nothing about an exact time.
- Before recording, recheck the Scheduled page and the plan limits on OpenAI's Scheduled tasks page. If labels or limits changed, update the script and the written lesson together.
- Use a modest window at 125% zoom and the kit's one pink highlight style. Record a human voice, with 2 to 5 second pauses after each click.
- Upload captions from the Audio column, and publish this script as the transcript beside the written lesson.
- The narration names every on-screen action, so it also covers audio description.
