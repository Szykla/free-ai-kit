Production notes:
- Record in a clean demo ChatGPT account on the desktop app, with no connected apps, no memory and no notifications. Use only the two sample files.
- Window about 1280 by 800 with larger text so it reads on phones. Use the kit's pink highlight box only.
- Agent replies vary between runs. Record two runs and use the one whose plan and table match the structure in the narration. Never edit the numbers on screen.
- Pause 2 to 3 seconds after each click that changes the screen. Use a real human voice at a conversational pace.
- Captions: upload the Audio column, edited, as the caption file. Publish it with the written lesson as the transcript.
- If Work moves or is renamed, re-record rows 2 and 6 first. Check plan availability on the OpenAI help page on the day you record.
