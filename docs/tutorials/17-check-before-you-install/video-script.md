## Production notes

- Use a made-up repository for the lookalike scene. Never show or link a real malicious repository, and never download its release.
- Use 125% browser zoom so text reads on phones. Use the kit's one pink highlight box.
- Before recording, run the six-point prompt again in the app you show. If the reply format changed, update the sample reply in the script and the written lesson together.
- Use a human voice at a conversational pace. Pause 2 to 5 seconds after each typed message.
- Upload captions made from the Audio column, and publish this script as the transcript next to the written lesson.
