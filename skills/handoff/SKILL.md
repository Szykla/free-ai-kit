# Handoff

Compact what you know into one note so the next agent starts working, not asking.

Write these sections, each as short as it can be:
1. **Goal**: what "done" looks like, in the person's words.
2. **State**: what's finished, what's half-done, what's untouched.
3. **Decisions made**: and why, so they aren't reopened.
4. **Where things are**: files, links, commands, with exact paths.
5. **Next step**: the very next action, concrete enough to start without questions.
6. **Watch out**: anything that failed, surprised you or must not be done.

Leave out the story of how you got here. Never put keys or passwords in the note.
