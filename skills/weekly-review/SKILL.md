# Weekly review

## 1. Read
Their goals or plan file if they have one, last week's review if it exists, and
whatever sources are connected (calendar, tasks, notes). Name any source you couldn't
read.

## 2. Write five short sections
1. **Done**: what moved, tied to a goal where possible.
2. **Stuck**: what didn't move, and the one thing blocking each.
3. **Changed**: anything new that affects the plan (a deadline, a cost, a person).
4. **Drop**: one commitment, routine or schedule to stop, and why.
5. **Next week**: at most three priorities, each with a first step.

## 3. Keep it honest
- Compare with last week's "Next week". Say plainly what didn't happen.
- Figures (money, hours, health) only from their data. Never estimate silently.
- Under one screen. If it's longer, cut.
